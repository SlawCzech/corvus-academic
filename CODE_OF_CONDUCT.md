# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas rather than people, and keep
discussions about the project. Harassment, personal attacks and publishing other people's
private information are not tolerated.

Report unacceptable behaviour to the maintainer, [@SlawCzech](https://github.com/SlawCzech),
or use GitHub's **Report content** option on the comment or issue in question.
Reports are handled confidentially; the maintainer may remove comments, close issues or
block participants who break these rules.
